# Política de segurança

## Relatando uma vulnerabilidade
**Não abra uma issue pública.** Use o recurso *Security advisories* do GitHub
(<https://github.com/AprendendoLinux/corujabackup/security/advisories/new>) ou escreva para o mantenedor pelo
site <https://henrique.tec.br>. Informe versão, passos para reproduzir e impacto. Respondemos em até 7 dias.

## Versões com correções
Enquanto o projeto estiver na série `0.0.x`, apenas a **versão mais recente** recebe correções.

## Boas práticas de implantação
Veja [docs/SEGURANCA.md](docs/SEGURANCA.md) (modelo de ameaças e checklist de endurecimento).
