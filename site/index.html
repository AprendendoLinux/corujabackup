Coruja Backup

Sistema de backup centralizado, em Docker e gerenciado por interface web. Um servidor orquestra tudo e agentes leves rodam nas máquinas protegidas. Código aberto, licença MIT.

Envio para a nuvem

O Coruja envia os arquivos de backup para a sua própria conta no Google Drive, OneDrive ou Dropbox, depois que você autoriza o acesso. Este endereço identifica o aplicativo de autorização usado nesse login.
