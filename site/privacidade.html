Política de privacidade

Atualizada em 26/11/2026.

Quem trata os seus dados

O Coruja Backup é um software auto-hospedado: ele roda nos servidores de quem o instala. Os autores do projeto não operam nenhum serviço que receba, armazene ou processe os seus arquivos, tokens ou dados pessoais.

O que o aplicativo acessa na sua conta

  • Google Drive: apenas o escopo drive.file, que permite ver e gerenciar somente os arquivos e pastas que o próprio Coruja criou, e o escopo de e-mail, para mostrar qual conta está conectada.
  • OneDrive/SharePoint: Files.ReadWrite, offline_access e User.Read.
  • Dropbox: pasta do aplicativo (App folder), com leitura e escrita de arquivos e identificação da conta.

Onde ficam os tokens e os arquivos

Os tokens de acesso e de renovação ficam cifrados (AES-256-GCM) no servidor Coruja de quem o instalou, nunca em servidores dos autores. Os backups vão do agente direto para a conta de nuvem do próprio usuário.

Uso dos dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados são usados apenas para realizar e conferir os backups que o usuário configurou; não são vendidos, compartilhados com terceiros nem usados para publicidade.

Revogar o acesso

Remova a conta de nuvem na interface do Coruja e revogue o acesso em myaccount.google.com/permissions (Google), account.live.com/consent/Manage (Microsoft) ou nas configurações de aplicativos do Dropbox.
